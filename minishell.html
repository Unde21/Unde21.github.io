Le projet

Un shell inspiré de bash, écrit en C à deux : lexer, parser, expansion des variables et des quotes, puis exécution avec fork(), execve(), pipe() et dup2(). Le prompt affiche ✅ ou ❌ selon le code de retour de la dernière commande.

À essayer

  • pipes |, redirections < > >> et heredoc <<
  • $VAR, $?, quotes simples et doubles, wildcards *
  • builtins : echo -n, cd, pwd, export, unset, env, exit
  • Ctrl-C pendant sleep 10 ou cat, Ctrl-\, Ctrl-D pour quitter
  • help liste les commandes de /bin

Sous le capot

Le code C de minishell est compilé en WebAssembly, sans modification. Un petit noyau en JavaScript lui fournit les appels système : chaque processus a sa propre instance et sa mémoire, et fork() copie cette mémoire dans l’enfant comme un vrai fork. Les commandes de /bin (ls, grep, sort…) sont réécrites en JavaScript ; les fichiers vivent en mémoire et disparaissent au rechargement.
