The project

A bash-like shell written in C by a team of two: lexer, parser, expansion of variables and quotes, then execution with fork(), execve(), pipe() and dup2(). The prompt shows ✅ or ❌ depending on the exit status of the last command.

Things to try

  • pipes |, redirections < > >> and heredoc <<
  • $VAR, $?, single and double quotes, wildcards *
  • builtins: echo -n, cd, pwd, export, unset, env, exit
  • Ctrl-C during sleep 10 or cat, Ctrl-\, Ctrl-D to quit
  • help lists the commands in /bin

Under the hood

Minishell’s C code is compiled to WebAssembly without changes. A small kernel written in JavaScript provides the system calls: each process has its own instance and memory, and fork() copies that memory into the child like a real fork. The commands in /bin (ls, grep, sort…) are rewritten in JavaScript; files live in memory and are gone on reload.
