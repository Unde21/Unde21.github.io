      The project
      
      
      A small infrastructure built with Docker Compose, one service per container, each image written from debian:bookworm: nginx as the only entry point (TLS 1.2/1.3 on port 443), WordPress on PHP-FPM, and MariaDB, with bind-mounted volumes and Docker secrets for every password. Bonus services: Redis cache, Adminer, cAdvisor, an FTP server and a static site.

      Why no live demo
      
      
      Docker needs a Linux kernel (namespaces, cgroups, overlay file systems), which a browser does not have. Instead, everything here is driven by the project’s own files, shown as they are in the repository.
