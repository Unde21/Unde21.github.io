    The project
    
      
    An HTTP/1.1 server written from scratch in C++98 by a team of three: a configuration file in the spirit of nginx, one non-blocking epoll loop for every connection, static files, uploads, DELETE, custom error pages, chunked transfer and CGI. The darts website you browse above was made by the team to test it.
    
    
    
    
    
      
    What is real
    
      
      
        
    • every page, image and redirect above is answered by webserv’s own code, from www/config
      • 
        
    • CGI scripts are started with fork() + execve(), their output read from a pipe and sent back chunked
      • 
        
    • accounts live in the server’s memory, as in the original
      • 
        
    • CGI scripts are JavaScript here, because there is no Python in the browser; one /cgi-bin/ location is added to the config for them
      • 
      
    
    
    
    
    
      
    Under the hood
    
      
    The C++ code is compiled to WebAssembly unchanged. A small kernel in JavaScript gives it sockets, epoll, pipes and processes on a virtual network. A Service Worker catches the requests made by the frame above and the page turns each into a raw HTTP request on localhost:8080, exactly the bytes shown in the list.
